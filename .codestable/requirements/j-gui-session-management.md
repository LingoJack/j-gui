# 会话管理

## 用户故事

- 作为一个跟 AI 聊了很多话题的人，我希望左侧能看到所有历史会话，按今天、昨天、更早自动分好，而不是在一堆文件里翻。
- 作为一个临时被打断的人，我希望切到另一个会话问个急事，再切回来继续刚才的话题，上下文还在。
- 作为一个想清理的人，我希望把暂时不用的会话归档起来，之后还能搜索到并恢复；彻底不要的再删除。

## 为什么需要

AI 对话不是一次性的——一个话题可能持续几天，中间穿插别的任务。没有会话管理，要么全堆在一个窗口里上下文越来越长，要么每次新开丢失历史。j-cli 已有会话存储（JSONL），但终端里只能看到文件名，桌面端可以把"浏览、切换、搜索"做成自然操作。

## 怎么解决

左侧栏列出所有会话，按日期分组折叠。点击会话切换，右键可置顶、归档或删除；归档项可在 archived 视图中查看，也能继续被搜索命中并打开。顶部搜索框既支持按标题模糊过滤，也支持按消息内容命中并打开到对应消息锚点。当前会话的上下文自动持久化，切换时不丢失。数据复用 j-cli 已有的存储格式，不另建一套。

## 边界

- 不做跨工作区、跨外部数据源的统一全文检索；当前范围只覆盖本地 Chat / Agent 会话内容搜索。
- 不导出会话（Markdown/PDF 等格式）。
- 会话数据存储在本地 `~/.jdata/`，不跨设备同步。
- 删除会话不可恢复。
